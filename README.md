🔐 Smart Door Lock System Using ESP32

An IoT-enabled smart door security system using ESP32, fingerprint authentication, servo-controlled locking, door-status monitoring, and Telegram notifications.

🚀 Features

- Fingerprint-based authentication
- Servo-controlled door locking
- Door-status monitoring
- Buzzer and LED indication
- Wi-Fi connectivity
- Telegram alerts for unauthorized access
- Security response to repeated failed attempts

🧪 Simulation

The system was also tested using Wokwi simulation to verify the control logic and component interaction.
